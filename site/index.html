Compresser

Maj liste les formats. Alt ajoute les outils, puis les mêmes formats. La touche reste libre pour Alt+Tab et Ctrl+C. Échap ferme la roue.

Actions

N'importe quel fichier, puis Ctrl.

Le fichier

Copier le chemin

Chemin et Explorateur

Le chemin complet va dans le presse-papiers, ou le dossier s'ouvre dans l'Explorateur avec le fichier visible.

Terminal

Une fenêtre s'ouvre dans le dossier du fichier. Pratique juste avant une commande.

Copier

Une copie est écrite à l'endroit choisi. Si le nom existe déjà, Cinder en trouve un autre.

Déplacer

Le fichier change de dossier. La conversion, elle, ne déplace jamais l'original : elle écrit à côté.

Ctrl reste libre pour les raccourcis du système. La roue des actions ne compte pas dans les minutes gagnées.

Sur la machine

Les fichiers ne partent pas.

Un convertisseur en ligne demande une copie. Cinder lit le fichier là où il est, et écrit le résultat dans le même dossier.

Rien n'est envoyé

Pas de compte, pas de serveur Cinder. La vidéo et l'audio passent par ffmpeg, déjà installé sur le PC.

L'original reste

Jamais d'écrasement. Si le nom existe déjà, Cinder choisit le suivant. Deux minutes sont comptées par fichier converti.

Lancer

Un clic, et la roue
est là.

Le fichier s'installe dans ton compte. Le raccourci arrive sur le bureau et dans le menu Démarrer, et le tableau montre les minutes gagnées.

Cinder pour Windows

  • Maj convertit, Alt ajoute les outils, Ctrl agit sur le fichier
  • L'icône à côté de l'horloge indique si Cinder est activé
  • Fermer le tableau le cache. Quitter se fait dans le menu de l'icône
Télécharger

Windows 10 ou 11. L'installation ne demande pas les droits administrateur.
